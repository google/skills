## 2. Systemic Active Directory & Tier-0 Escalation Vectors Across CISA Assessments

Across `AA26-237A`, `AA24-317A`, and `AA24-190A` (*SILENTSHIELD*), CISA Red Teams repeatedly achieved Domain Admin and sensitive business system (SBS) compromise via four structural misconfigurations:

1. **Non-Zero Machine Account Quota (`ms-DS-MachineAccountQuota` / `T1136.002`)**:
   - In Org A (`MAQ = 10`) and Org B (`MAQ = 1,000`), unprivileged domain users created attacker-controlled computer accounts (`Event ID 4741`) and proxied traffic (`T1090.001`) through compromised hosts to evade EDR host restrictions. Enforce `ms-DS-MachineAccountQuota = 0`.
2. **ADCS ESC1 Template Misconfigurations (`T1649`)**:
   - Templates with `CT_FLAG_ENROLLEE_SUPPLIES_SUBJECT` enabled allow low-privileged users to enroll certificates specifying arbitrary Subject Alternative Names (SANs) of Domain Admins (`Event ID 4887`).
3. **SCCM & Tier-0 Endpoint Configuration Managers (`T1033`)**:
   - Red Teams queried SCCM distribution points to map user-to-device relationships, extracted cleartext service account passwords from SCCM XML files (`AllExtendedRights` -> DCSync `T1003.006`), and harvested SQL Developer passwords (`connections.json`, `product-preferences.xml`) and static AWS IAM keys from Distributed File System (DFS) root shares.
4. **Hybrid AD Connect Credential Dumping (`ADConnectDump` / `T1003`)**:
   - Extracted cleartext credentials for `MSOL_` and `Sync_` synchronization accounts from the Entra ID Connect server to enumerate cloud tenants via `AzureHound` and `ROADrecon`.
5. **Proactive LOTL Execution Lockdown & Hardening (`CISA/NSA/ACSC Identifying & Mitigating LOTL Techniques` - `WDAC`, `AppLocker`, `JEA` & `CLM`)**:
   - Restrict arbitrary LOLBin, script, and driver execution via **Windows Defender Application Control (`WDAC`)** (`Microsoft-Windows-CodeIntegrity/Operational` Event IDs `3076` Audit / `3077` Block) and **AppLocker** (`Microsoft-Windows-AppLocker/EXE and DLL` & `MSI and Script` Event IDs `8003`/`8004` & `8006`/`8007`).
   - Enforce **PowerShell Just Enough Administration (`JEA`)** on WinRM endpoints (`TCP/5985`/`5986`) to restrict administrative sessions to role-scoped cmdlets, and enforce **PowerShell Constrained Language Mode (`__PSLockdownPolicy = 4`)** for non-admin sessions to block arbitrary `.NET` reflection and Win32 API calls.

## 3. Mandiant M-Trends (2025-2026): Cloud Vishing Surge (`23%`), Cascading Third-Party SaaS / NHI Compromises & Infostealers

### A. Cloud Initial Infection Vector Reversal (M-Trends 2025 p.34 vs. M-Trends 2026 p.38, 74-77)

* **Vishing Surges to `#1` in Cloud Compromises (`23%`)**: While Email Phishing dropped from `22%` (2022) -> `14%` (2024) -> **`6%` (2025)** across all investigations, **Voice Phishing (Vishing) surged to `#2` overall (`11%`) and `#1` in Cloud Compromises at `23%`** (up from `6%` in M-Trends 2025), followed by **Stolen Credentials (`20%`)** and **Third-Party Compromise (`17%`)**. Data theft occurred in **`77%` of all cloud compromises** (up from `66%`).
* **ClickFix Web Compromise Lures (`8%` Global Initial Vector in M-Trends 2026)**: Compromised websites display fake Cloudflare CAPTCHA, browser update, or Google Meet microphone-fix overlays instructing users to press `Win+R` (`explorer.exe`), paste (`Ctrl+V`) a clipboard command (`powershell.exe -w hidden -enc ...` or `mshta.exe http...`), and press Enter, delivering `LummaC.V2`, `DARKGATE`, or `FAKEUPDATES`.

### B. Cascading Third-Party SaaS & Non-Human Identity (NHI) Compromises (`UNC6395`, `UNC6040`/`UNC6240`, `UNC6564`, `UNC3944`)
Mandiant M-Trends 2026 (p.74-77) highlights that attackers increasingly bypass hardened human MFA by targeting **Non-Human Identities (NHIs)** (OAuth tokens, Service Principals, API keys, and connected SaaS apps):

1. **`UNC6395` (`GATO-X` GitHub Actions Compromise -> Salesloft Drift -> Salesforce -> `TruffleHog` & AWS `GetCallerIdentity` / `STS` Enumeration)**:
   - Exploited misconfigured GitHub Actions workflows (`pull_request_target` / `workflow_run`) using the open-source **`GATO-X`** tool to steal OAuth tokens belonging to a third-party SaaS integration (**Salesloft Drift**).
   - Used the compromised SaaS integration's OAuth tokens to authenticate directly into hundreds of downstream **Salesforce** customer environments, mass-exporting `Account`, `Contact`, `Case`, and `Opportunity` tables.
   - Ran **`TruffleHog`** against exported support cases and internal repositories to harvest hardcoded AWS IAM keys, Snowflake credentials, and OAuth client secrets, immediately executing **AWS `GetCallerIdentity` (`sts:GetCallerIdentity`) and `STS` role enumeration from untrusted ASNs / residential proxies** to pivot into multi-cloud infrastructure.
2. **`UNC6040` & `UNC6240` (*ShinyHunters* Vishing & Malicious Connected OAuth Apps)**:
   - `UNC6040` vished employees posing as corporate IT helpdesk staff, directing victims to Salesforce's connected app authorization page (`login.salesforce.com/services/oauth2/authorize` or trial domain) to approve a rogue **Salesforce Data Loader** OAuth app; `UNC6240` then extorted victims using the exfiltrated CRM data.
3. **`UNC6564` ("Living off the Cloud" Identity LOTL), `QUIETVAULT`/`PROMPTFLUX` AI Malware & `UNC5267` DPRK IP-KVM Insider Threats**:
   - **`UNC6564` Cloud Identity LOTL**: Executes **AWS IAM Identity Center SSO `DeviceCode` phishing (`CreateToken` with `grantType=urn:ietf:params:oauth:grant-type:device_code`)**, **GCP `setIamPolicy` and `CreateServiceAccountKey` (`iam.serviceAccounts.keys.create`) privilege escalation**, and native cloud VM script execution (AWS `SSM SendCommand`, Azure `RunCommand`, GCP `setMetadata` startup scripts).
   - **`QUIETVAULT` & `PROMPTFLUX` AI-Assisted Developer Credential Harvesting**: `QUIETVAULT` (malicious npm stealer) invokes local AI coding CLIs (`claude`, `gemini`, `copilot`, `aider`) or filesystem scans targeting developer **`.env`, `.npmrc`, `.pypirc`, SSH keys (`id_rsa`), and GitHub tokens**, while `PROMPTFLUX` / `PROMPTSTEAL` invoke external LLM APIs (`api.openai.com`, `generativelanguage.googleapis.com`) from unsigned scripts in `/tmp` or `AppData` to dynamically rewrite code.
   - **`UNC5267` DPRK Fraudulent Remote IT Workers (`122-Day` Median Dwell Time, M-Trends 2025/2026 & FBI PINs)**: Operatives route corporate laptops at US residential "laptop farms" through hardware **IP-over-KVM switches (`TinyPilot`, `JetKVM`, `PiKVM`, or Linux Composite USB Gadget `USB\VID_1D6B&PID_0104`)** paired with remote desktop utilities (**`AnyDesk`, `RustDesk`, `TeamViewer`, `Chrome Remote Desktop`**) and anomalous **residential proxy, VPS, or `Astrill VPN` logins**.
4. **`UNC3944` (*Scattered Spider* SSO VM Spawning) & `UNC5537` (Snowflake `SNOWSQL_CLI` Infostealer Campaign)**:
   - **`UNC5537`** queried underground infostealer logs (`VIDAR`, `LUMMA` [`LummaC.V2`], `REDLINE`, `RACCOON`) for single-factor Snowflake credentials, authenticating via **`SNOWSQL_CLI` (`application_name = "SNOWSQL_CLI"`) without MFA** from untrusted ASNs to bulk-exfiltrate customer tables (`COPY INTO` / `SELECT *`).

### C. Infostealer Marketplace (`UNC5537` Snowflake & `TRIPLESTRENGTH`) & Unsecured Internal Repositories (M-Trends 2025 p.48-51, 74-78)

* **`UNC5537` (Snowflake Customer Campaign) & `TRIPLESTRENGTH` (Cloud Cryptomining)**:
  - `UNC5537` queried underground infostealer logs (**`VIDAR`, `LUMMA` [`LummaC.V2`], `REDLINE`, `RACCOON STEALER`, `RISEPRO`, `METASTEALER`**, including contractor personal/gaming PC infections dating back to 2020) for single-factor Snowflake credentials (`SnowSQL` / web sessions without network allowlists) to bulk-exfiltrate customer data tables.
  - `TRIPLESTRENGTH` harvested `RACCOON` stealer logs and browser cookies to hijack AWS, GCP, Azure, and Linode service accounts for illicit cryptomining.
* **Unsecured Internal Data Repositories (`SharePoint`, `GitHub Enterprise`, `Confluence`, `Jira` - M-Trends 2025 p.74-77)**:
  - Immediately after obtaining standard employee credentials or vishing access, both Mandiant Red Teams and threat groups (`APT29`, `FIN11`, `UNC2891`, `UNC3944`) query SharePoint and GitHub search APIs for `.pem`, `.key`, `id_rsa`, `.env`, `.kdbx`, `connections.json`, and `password` to escalate privileges across segmented cloud VLANs.
